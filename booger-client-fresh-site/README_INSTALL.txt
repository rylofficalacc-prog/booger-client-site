Booger Client fresh website

Option A: replacing your current site
1. Copy app/page.tsx from this folder.
2. Replace your existing app/page.tsx on GitHub.
3. Commit changes.
4. Wait for Vercel to deploy.

Option B: new Vercel project
1. Upload this whole folder to a new GitHub repo.
2. Import the repo on Vercel.
3. Framework preset: Next.js.
4. Deploy.
